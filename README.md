This project contains code that pertains to a Computational Medicine Assignment, for the program, Msc. Biomedical Engineering taught at Mbarara University of Science and Technology. It addresses the question; 

A patient presents with a high-grade glioma.
- What sample type can be used to diagnose such a patient?
- Which imaging features predict treatment outcomes?
- Perform tumor segmentation or feature extraction from MRI images. This can be a simpe descriptive code to show us how you approach this problem, from literature, you can actually identify which features your model would capture. A concetual framework can be used for description as well

This is an application of medical image processing and machine learning to brain tumour segmentation and quantitative feature extraction.
